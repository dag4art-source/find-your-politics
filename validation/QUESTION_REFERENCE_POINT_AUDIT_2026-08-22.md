# Question reference-point audit - 2026-08-22

## Trigger
Reddit feedback correctly identified a questionnaire-design problem: some answers used comparative wording such as "higher", "lower", "more", "less" or "stronger" without making the comparison point explicit. A respondent should not have to guess whether an option means compared with today, compared with another income group, or simply an absolute ideological position.

## Audit rule
Each live question was reviewed using this rule:

1. If an answer describes a **change from the current Swedish system**, the question or answer should say **compared with today / today's level / today's system**.
2. If the question is intended to measure an **absolute preferred policy design**, answer options should describe absolute positions rather than unexplained comparative language.
3. Hypothetical trade-off questions do not need a current-policy reference when the scenario itself defines the comparison.
4. Wording corrections should not change the dimension, score direction or score value unless a separate methodological review justifies that change.

## Clear reference-point fixes applied

### Q003 - High employment-income tax
Problem: "Top earners should pay substantially more" could mean more than today or more than other earners.
Fix: explicitly anchors the scale to today's tax system.
Scoring unchanged.

### Q006 - State ownership
Problem: answers mixed relative language ("own more", "sell most") with absolute descriptions.
Fix: converted the scale to absolute preferred levels of state commercial ownership.
Scoring unchanged.

### Q007 - Employment protection / labour flexibility
Problem: several options were changes from the current system but the question did not define the baseline.
Fix: explicitly asks how the balance should change compared with today.
Scoring unchanged.

### Q017 - Asylum policy
Problem: options mixed "more open than today" with "more restrictive" without stating the same reference point for the whole scale.
Fix: question explicitly uses today's policy as the baseline and all comparative options now follow that reference.
Scoring unchanged.

### Q018 - Skilled migration
Problem: "more restrictive" and "substantially more talent" lacked a common explicit reference point.
Fix: question and options now use today's openness as the baseline.
Scoring unchanged.

### Q028 - School choice
Problem: options mixed "less", "some", "broad" and "expand further".
Fix: converted the scale to absolute levels of preferred school choice, from limited to very broad.
Scoring unchanged.

### Q038 - Defence spending
Problem: "reduce", "increase" and "major additional increases" implicitly depended on an unstated baseline.
Fix: explicitly asks how spending should develop from today's level over the next few years.
Scoring unchanged.

### Q042 - Scope of government
Problem: the question asked for an absolute preferred role, while the extremes used relative language such as "broader" and "much smaller".
Fix: converted those options to absolute descriptions of government scope.
Scoring unchanged.

## Questions retained for a later wording review, not automatically changed

### Q004 - Tax on large accumulated assets
The V2 question is conceptually clear but some answer language still uses "more", "low" and "reduce". Changing it safely may require deciding whether the dimension represents desired tax level, tax mix, or change from current Swedish taxation. That is a modelling question, not merely copy editing.

### Q010 - Unemployment insurance generosity
The scale combines generosity, duration and activity requirements. A simple "compared with today" edit would not fully solve that multidimensionality.

### Q011 - Sickness insurance
Likewise combines generosity, eligibility, rehabilitation and time limits. Needs a separate construct-purity review rather than cosmetic wording changes.

### Q024 - Rent regulation
The options combine strength of regulation, reform for new construction and market pricing. The baseline is partly visible, but the construct is broader than a single stronger/weaker scale.

## Conclusion
The Reddit criticism was valid but not a reason to convert every political question into a current-policy comparison. The better rule is:

- use an explicit baseline where the construct is **direction of change from the current system**;
- use absolute descriptions where the construct is **preferred policy design**;
- preserve scenario-defined trade-offs as scenarios.

Eight clear wording problems were corrected without changing any scores or dimensions. Four broader questions remain flagged for later construct review.
